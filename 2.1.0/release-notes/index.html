    SPRINT-Nav Release Notes

    Release note applicability

    These release notes contain information on the latest recommended versions of software for SPRINT-Nav products, including:

    • SPRINT-Nav U (type number 8358)
    • SPRINT-Nav M (type number 8425)
    • SPRINT-Nav (type number 8384)
    • SPRINT-Nav DP (type number 8388)

    Release note introduction

    Release note terminology

    Releases will be described by the month and year of their release, e.g. "SPRINT-Nav release July 2026". Unless explicitly stated otherwise, it should be assumed that the latest release builds on the previous release.

    Not all SPRINT-Nav software releases will be applicable to all SPRINT-Nav hardware versions. The software versions applicable to the release will be shown in a table as below.

    Product Status Version
    SPRINT-Nav U Not available x.x.x.x
    SPRINT-Nav M Not available x.x.x.x
    SPRINT-Nav Recommended x.x.x.x
    SPRINT-Nav DP Not available x.x.x.x

    Alongside the above, the recommended versions for supporting products will also be provided.

    Releases will be classified as below.

    Classification Information
    Not available A release with this functionality is not available for this hardware version of SPRINT-Nav
    Recommended This release contains recommended feature or performance improvements
    Semantic Versioning

    Sonardyne use semantic versioning whereby the following rules apply:

    V a.b.c+dddd where:

    • a = major revision number (range 0 – x, no leading zeros)
    • b = minor revision number (range 0 – x, no leading zeros)
    • c = interim release number (range 0 – x, no leading zeros)

    • d = build ID (optional, 0001 – xxxx)

    • Major Revision Number – This number should be increased whenever a change is made that is not backward compatible with the previous version of the f/w or s/w (e.g. changed or removed commands, interfaces, protocols or configuration parameters). When increased, the minor revision and interim release numbers are reset to 0. Major revision 0 indicates initial development, where the interface is not yet stable.

    • Minor Revision Number – This number should be increased whenever new backward-compatible functionality is added to the f/w or s/w, or existing functionality is deprecated. When increased, the interim release number is reset to 0.
    • Interim Release Number – This number should be increased whenever a new release of an existing released version is required to make backward-compatible bug fixes only.
    • Build ID – This optional ID, appended after a "+", identifies a specific build of a version. It is ignored when determining which version is newer, so any new release must receive a new a.b.c number.

    October 2026 SPRINT-Nav release (2.01)

    This software release is focused on implementing LBL range aiding features for a future Fusion 2 release and contains improvements for users who rely on HNAV for vehicle control.

    Alongside the above the release notably includes:

    • Adds the Watson/Tritech heading, pitch and roll message.
    • Updates HNAV to version 2, now containing accelerations.
    • Increases DVL maximum operation rate.
    • Adds an "operational" settings area for configuring advanced settings.
    • Chart improvements.
    • Allows users to configure a blanking distance from the DVL to achieve more reliable bottom lock and to reduce the impact of aeration/noise when on the sea surface.
    • Adds LBL aiding functionality to SPRINT-Nav via API.
    • Bug fixes.

    Features

    The features below improve performance, user experience or add functionality to SPRINT-Nav:

    ID User Value
    891 Displays 2D distance between SPRINT-Nav position and USBL aiding sensor, helping monitor drift when other aiding is disabled.
    1241 Displays 2D distance between SPRINT-Nav position and GNSS aiding sensor, helping monitor drift when other aiding is disabled.
    1242 Adds pop-up notifications when an external API, e.g. Fusion 2, changes SPRINT-Nav settings, improving visibility and traceability.
    1243 Adds a clear connection indicator and alerts for Fusion 2 links, showing when SPRINT-Nav is connected or disconnected.
    1247 Adds a configurable minimum altitude (blanking distance) to prevent DVL tracking off the sea chest, improving navigation reliability.
    1584 Adds water-track data to the PD4 output message.
    1693 Adds depth and altitude to the chart display and reorganises layout for clearer ROV/vehicle situational awareness.
    1904 Adds support for 15 Hz and 20 Hz DVL output rates, increasing maximum data update rate beyond 10.5 Hz.
    1984 Adds all amber and red alarm events to the event log for full real-time traceability of system alerts.
    2077 Introduces an updated HNAV output message format (HNAV V2).
    2078 Adds a locked operational settings area for configuring raw DVL logging, onboard logging, and battery charging.
    2082 Improves the LBL chart display with free pan/zoom and consistent error ellipse scaling to match Fusion 2.
    2083 Improves the LBL data view with clearer beacon and ranging tables, plus human-readable status messages for ranges.
    2088 Adds the ability to enable or disable DVL aiding in the INS and AHRS from the web UI, Fusion 2, or API.
    2089 Adds SFTP connection details directly to the web UI, making log retrieval easier to find.
    2090 Introduces LBL range aiding licence tiers, letting users unlock Fusion 2 or API-driven autonomous LBL range aiding.

    2934 Adds XPOS support to SPRINT-Nav DP. Note: XPOS cannot be enabled on the dashboard, only via the aiding tabs.

    Notes

    • Sonardyne recommend use of the gRPC or framed API. JSON will be deprecated in a future release. Contact support@sonardyne.com referencing these release notes if this is an issue.
    • For DP systems the API may be used to configure USBL and vertical aiding settings, but these aiding sensors are not available on DP systems, so cannot be used.
    • Port link cannot be configured via the User Interface in this release. Port configuration will be carried over from the previous software release and this issue (3526) will be fixed in the next release.
    • The SPRINT-Nav web User Interface has been updated and may not work on older browsers; use the latest versions of Firefox/Chrome.
